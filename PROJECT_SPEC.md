# Project specification

OrderFlowSage 0.1.0 validates and replays full limit-order-book snapshots with declared sequence numbers. It produces deterministic per-event microstructure features, fixed-size aggregate windows, canonical evidence hashes, and explicit integrity claims.

Stable commands are `run`, `verify`, `summary`, `prompt`, and `demo`. The schema contains no endpoint, credential, prediction, signal, order, or execution action.
